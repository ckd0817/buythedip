# 抄底

Cloudflare Workers 前端部署与 VPS 行情后端连接见 [部署说明](deploy/WORKERS.md)。

初始入口为 SPY、QQQ、SMH，支持搜索美股、沪深 A 股、港股或 ETF 代码。查询成功后追加自定义标签，按实际宽度容纳多个；满时从左向右替换最左侧标的，包括初始三个入口。标签统一等宽，不提供关闭按钮；列表在当前浏览器保存，刷新后恢复。支持中英文、深色模式、手机适配和历史图表逐图滚动过渡。

## 数据与计算

使用 Yahoo Finance 拆股、分红调整后的日收盘序列。历史最高点取截至当日的全部可用历史；页面收盘价显示原始 close，价格曲线显示 adjusted close。

回撤深度 D[t] = 1 - adjustedClose[t] / runningMax[t]。

抄底指数：当前回撤深度与此前已恢复前高的回撤事件最大深度比较。每次从离开历史前高到恢复前高为一个事件，中途反弹不拆分，不设最小深度；当前未结束事件不计入样本。count(事件最大深度 < 当前回撤) / 已结束事件总数 × 100；相同深度不计入分子。首页固定全部历史，图表范围不改变统计样本。后台保留有限年限快照用于兼容。每个历史时点只使用当时已结束事件，禁止未来数据回填。没有已结束事件时，处于回撤则留空；处于前高则为0。前端保留一位小数、上限99.9、不带百分号。drawdownEventCount 为事件样本数，兼容字段 drawdownSampleCount 同值。计算版本5，旧版本缓存不得作为新算法降级结果返回。

RSI（14）使用Wilder平滑；MA200偏离使用200日简单均线。两者反向百分位，越超卖百分位越高。SPY→VIX，QQQ→VXN，SMH→VXSMH；个股仅展示确有对应关系的Cboe波动率，无对应数据时显示两张卡片。波动率历史不足时百分位留空。

首页不再提供统计年限选择，所有指标固定使用全部可用历史。历史图表顺序为抄底指数、调整后收盘价、回撤、RSI、MA200偏离、波动率。底部固定1年、3年、5年、10年四个展示范围快捷选项、起止日期和28px纯时间滑块；不足对应完整历史的选项置灰。

## 更新与缓存

固定快照落盘共享；动态标的使用服务端持久缓存、同代码并发合并、上游限速和退避。缓存数据可立即返回，后台刷新，用户调整图表范围不重新请求上游。新代码最多512个缓存项。精确价格序列保留用于重新计算，失败保留上一完整快照。

生产保留美股定时器，纽约时间工作日18:30、20:30更新固定标的；动态API后台更新已查询标的。CN/HK/JP定时器保持停用，其他市场指数不在当前产品范围。免费数据源沿用此前选择；技术接入不代表已取得公开展示或商用授权。

部署见 DEPLOYMENT.md。

## 分享卡片

首页分享入口生成1080×1920 PNG。上方为粗宋体金句与蓝色抄底指数，下方使用横线分隔表格，回撤/收盘价与RSI (14)、MA200偏离、实际对应波动率共用四列对齐；缺少波动率时省略该行。首页与卡片统一标为“回撤”，英文为Drawdown。

分享弹窗仅有“添加文字”开关，默认开启并填入预置句，可直接编辑或换一句。关闭时隐藏编辑区并保留草稿，再次开启恢复草稿；关闭开关或清空文字都能导出，卡片会自动使用无文字布局。

27条预置金句分为0.0、(0,50]、(50,99.9]三档；各档采用洗牌袋抽取，一轮内不重复，轮次交界也避免连续重复；抽取进度保存在当前浏览器，重新打开、切换标的/语言及刷新后继续。中文自定义最多28个Unicode码点，英文80个，按实际字宽缩放换行以避免溢出。所有内容在浏览器Canvas本地生成，不上传自定义金句。思源宋体Heavy用于金句、指数标题及标语；思源黑体Bold用于数据，Heavy斜体处理用于标识；Archivo Black用于大数字。字体按OFL许可打包并保留许可证，仅打开分享时加载，避免依赖设备字体。

网站链接仅含带市场后缀的etf参数；旧years参数会被忽略并移除。支持保存PNG、复制链接；浏览器支持系统分享时，可传递卡片文件和链接，不支持文件分享时改用链接分享。系统分享能否同时保留图片、文案和URL取决于目标应用。自定义句子不会写入网站链接。

## A股与港股查询

数字6位默认按沪深代码识别：600519→600519.SS，000001→000001.SZ；支持SH/SZ前缀及.SH/.SS/.SZ后缀。1至5位数字识别为港股：0700、00700、700.HK、HK00700均规范为0700.HK。美股BRK.B仍规范为BRK-B。标签显示数字短码，完整代码用于链接、缓存与市场识别。

Yahoo复权日线要求返回身份、币种、交易所时区与请求市场一致；使用各交易所本地日期和收盘边界，跳过未完成日线。人民币¥、港币HK$，无对应波动率时仅显示RSI和MA200。新增标的仍按共享持久缓存、并发合并及各市场收盘后的后台刷新处理，不开启已停用的指数入口或区域静态快照定时器。

## 基金与重名代码

六位纯数字搜索通过同一API的search参数同时检查股票/ETF与人民币场外基金。两个真实候选均存在时显示名称、类型和完整代码，用户选择后才进入；单一匹配直接进入，取消不切换，不记住自动默认类型。任一来源限流或临时失败时返回错误，避免误当成单一匹配。明确.SS/.SZ/.HK/.OF后缀和基金前缀直接按指定类型查询。基金标签与分享链接保留.OF。

基金数据仅解析天天基金公开JSON变量，不执行远程JS。普通日期按单位净值比例，分红及份额折算日期按披露增长率衔接为复权净值序列。首页/卡片显示四位小数单位净值；收益率型货币基金、非人民币份额暂不支持。净值滞后时15分钟后重试，共享缓存继续使用。

## 回撤分位刻度

辅助指标下方展示P10/P25/P50/P75/P90/P95/P99对应的已结束回撤事件最大深度；全部分位弹窗展示P0至P100，并定位到当前指数邻近分位。刻度采用按关键分位分段的坐标，各刻度点与等宽数值列中心对齐，当前指数在相邻关键分位之间插值定位；分段间距不代表等量百分位。P0为样本最浅回撤，P100为最深回撤。使用与指数相同的完整事件样本，线性插值位置为(n-1)*p/100；不设最小事件深度、排除当前未结束事件。空样本返回null并显示空值，禁止用0填充。精确数值保存在drawdownQuantiles数组（百分数深度为正数，UI显示负号），两位小数展示，极小值保留更多小数。

计算版本6，静态及动态持久缓存使用保存的精确调整后价格重算，原价格和日期不改动。深浅色与中英文均支持，关闭弹窗/Escape/点击遮罩可退出。
