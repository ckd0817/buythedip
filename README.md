# 抄底 · Buy the Dip

一个通过历史回撤数据，观察当前下跌幅度的股票、ETF 与基金分析网站。

**在线体验：[buythedip.kaida.sbs](https://buythedip.kaida.sbs)**

[功能介绍](#功能) · [计算方法](#抄底指数怎么算) · [本地运行](#本地运行) · [部署说明](#部署) · [反馈问题](https://github.com/ckd0817/buythedip/issues)

## 为什么做这个网站

看到价格回撤时，知道“跌了多少”，却不容易判断“这次在历史上算不算跌得多”。

「抄底」把当前回撤与历史上已经结束的回撤事件比较，用抄底指数展示当前下跌的历史位置，并提供辅助指标和历史走势，方便一起分析。

## 功能

- **抄底指数**：基于全部可用历史的完整回撤事件，比较当前回撤深度。
- **回撤分位**：展示 P10、P25、P50、P75、P90、P95、P99 对应的回撤深度，可查看全部分位。
- **辅助指标**：RSI (14)、MA200 偏离及其历史百分位；存在对应数据时展示波动率指标。
- **历史图表**：抄底指数、复权价格、历史回撤和辅助指标走势；支持时间范围滑块及 1、3、5、10 年快捷选择。
- **标的搜索**：默认提供 SPY、QQQ、SMH，支持查询美股、沪深 A 股、港股、ETF 和部分人民币场外基金。
- **分享卡片**：在浏览器中生成 9:16 PNG，支持预置文案、可选的自定义文字，以及复制标的链接。
- **跨设备访问**：适配手机和电脑，支持中英文、浅色与深色模式，保存当前浏览器的标的标签。

### 查询示例

| 类型 | 输入示例 |
| --- | --- |
| 美股 / ETF | `AAPL`、`QQQ`、`SMH`、`BRK.B` |
| 沪深股票 / ETF | `600519`、`000001.SZ`、`510300.SS` |
| 港股 | `0700`、`00700`、`700.HK` |
| 人民币场外基金 | `000001.OF`、`基金000001` |

六位纯数字同时匹配到股票与基金时，会显示候选名称和类型，由用户选择；也可输入完整市场后缀直接指定。收益率型货币基金和非人民币基金份额暂不支持。

## 抄底指数怎么算

价格序列采用拆股、分红调整后的日收盘价；基金使用分红、份额折算衔接后的净值序列。

```text
当前回撤深度 = 1 − 当前复权收盘价 / 截至当日的历史最高复权收盘价

抄底指数 = 最大回撤深度小于当前回撤的已结束事件数
         / 已结束回撤事件总数 × 100
```

一轮回撤从价格离开历史前高开始，到恢复至前高或创新高时结束。中途反弹不拆成新事件，不设最小回撤深度，当前尚未结束的事件不提前加入历史样本。

例如，抄底指数为 90，表示当前回撤深度超过了约 90% 的已结束历史回撤事件。它描述历史位置，不等同于未来收益或后续下跌的条件概率。

- 指数使用全部可用历史，保留一位小数，显示范围为 0.0～99.9。
- 恰好相同深度不计入分子；位于历史前高时为 0；处于回撤且没有完整历史事件时留空。
- 历史曲线中的每个时点只使用当时已结束的事件，避免使用未来信息。
- 图表时间范围只控制展示区间，不改变首页统计样本。
- 回撤分位使用相同的已结束事件样本，对排序后的最大深度进行线性插值；它与严格小于计数的指数并非精确反函数。

### 辅助指标

| 指标 | 计算与展示 |
| --- | --- |
| RSI (14) | 14 个交易日，使用 Wilder 平滑 |
| MA200 偏离 | 复权收盘价相对 200 日简单移动平均线的百分比偏离 |
| 波动率 | 仅展示存在对应关系的数据，例如 SPY → VIX、QQQ → VXN、SMH → VXSMH |

RSI 和 MA200 偏离越低，历史百分位越高；波动率越高，历史百分位越高。没有对应波动率数据的标的只显示 RSI 和 MA200；历史样本不足的指标百分位留空。

## 本地运行

需要 **Node.js 22 LTS**、**Python 3.12** 和 Git，以及能访问行情数据源的网络。

```sh
# 克隆并安装依赖
git clone https://github.com/ckd0817/buythedip.git
cd buythedip
npm ci
python -m pip install -r requirements.txt

# 首次运行：下载 SPY、QQQ、SMH 的真实历史数据并生成快照
npm run data:update -- --market US
```

在两个终端中分别启动后端和前端：

```sh
# 终端一：行情 API，默认监听 127.0.0.1:8081
npm run api
```

```sh
# 终端二：Vite 开发服务器
npm run dev
```

打开 [http://127.0.0.1:5173](http://127.0.0.1:5173)。Vite 将 `/api/` 请求代理至本地后端。

行情快照、原始数据和运行缓存不包含在 Git 仓库中。首次运行需要先生成快照；数据源限流或不可达时不会使用演示数据替代。

### 常用命令

| 命令 | 用途 |
| --- | --- |
| `npm run dev` | 启动前端开发服务器 |
| `npm run api` | 启动 Python 行情 API |
| `npm run data:update -- --market US` | 更新默认三个 ETF 的静态快照 |
| `npm test` | 运行前端逻辑、Worker 与 Python 测试 |
| `npm run build` | 类型检查并构建前端 |
| `npm run preview:worker` | 构建并在本地预览 Worker，行情回源地址由配置决定 |

## 数据与缓存

- **数据来源**：股票与 ETF 日线使用 Yahoo Finance，波动率使用 Cboe，场外基金使用天天基金公开数据。
- **收盘口径**：按交易所时区识别交易日，跳过未完成日线。页面收盘价显示原始价格，历史价格图与指标使用复权序列；基金显示单位净值。
- **后端缓存**：共享持久缓存、同代码并发合并、上游限速与失败退避；已有缓存优先返回并在后台刷新，失败时保留上一份完整结果。
- **定时更新**：线上默认 ETF 在纽约时间工作日 18:30、20:30 更新；已查询的其他标的由后端按市场收盘时间检查刷新。
- **边缘缓存**：当前 Workers 部署中，默认行情快照缓存 300 秒，代码查询结果缓存 60 秒，错误响应不缓存。

免费数据接口的技术可访问性不代表已取得公开展示或商用授权；自行部署时请核实所用数据源的使用条款。

## 部署

在线版本采用 **Cloudflare Workers Static Assets 托管前端 + Tunnel 连接 VPS 行情后端**。推送至 `main` 的前端改动由 Workers Builds 自动发布，Python 后端独立部署。

- [Cloudflare Workers 部署、验证与回滚](deploy/WORKERS.md)
- [Linux VPS 后端、Nginx 与定时任务](DEPLOYMENT.md)

**自行部署前，先修改 `wrangler.jsonc` 中的 Worker 名称、正式域名 Route 和 `ORIGIN_BASE` 回源地址。** 仓库当前配置绑定项目的在线站点，直接执行 `npm run deploy:worker` 会尝试发布配置中的正式路由。

分享字体随仓库保留各自的 OFL 许可证，见 [`public/fonts/`](public/fonts/)。
